# 🐾 Dr.Paw

### Healthier Pets. Happier Lives.

Dr.Paw is a modern iOS pet-care application designed to help pet owners manage their pets' everyday health, growth, reminders, and essential information in one place.

Built with **SwiftUI**, Dr.Paw focuses on providing a simple, friendly, and organized experience for taking better care of pets.

---

## 📱 About the Project

Dr.Paw was created as an iOS application that brings multiple aspects of pet care together in a single app.

Instead of keeping health records, reminders, growth information, and other pet-related details scattered across different places, Dr.Paw provides a centralized experience for managing them.

The project was also developed as part of **Shipaton 2026**.

---

## ✨ Features

- 🐶 **Multiple Pet Profiles**
  - Create and manage profiles for different pets.
  - Store important information about each animal.

- 📈 **Growth Tracking**
  - Track pet weight and height over time.
  - Visualize growth through charts.

- 💊 **Medical Reminders**
  - Create reminders for medications and other health-related activities.

- 🍖 **Food & Walk Tracking**
  - Keep track of feeding and walking activities.

- 🏥 **Nearby Veterinary Clinics**
  - Find nearby veterinary clinics using MapKit.

- 📸 **Pet Photos**
  - Capture and store memorable moments with your pets.

- 🐾 **Animal Information**
  - Explore information about different animal categories and breeds.

- 🔔 **Notifications**
  - Receive reminders for important pet-care activities.

- 🔐 **Authentication**
  - Secure user authentication and session management.

- 💳 **Subscriptions**
  - Subscription and paywall functionality powered by RevenueCat.

## 🎨 Design

Dr.Paw follows a warm, minimal, and pet-friendly visual identity.

The interface uses a neutral palette built around:

- Cream
- Taupe
- Near-black
- Soft brown accents

The goal was to create an interface that feels friendly and approachable while still maintaining a modern iOS design language.
